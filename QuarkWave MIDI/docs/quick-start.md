# QuarkWave MIDI quick start

**For:** development testers with the Pico and Uno connected. **Status:** source-reviewed, partial two-board check (firmware snapshot: 2026-09-23). The proposed physical A0 line output and DIN input are not built on the photographed instrument. The optional Uno USB-audio build has been recorded successfully in Logic Pro on the owner's Mac.

1. Power both boards by their separate USB cables. For sound **on the current development build**, use the [optional Uno USB-audio experiment in Logic Pro](network-midi-setup.md#record-the-sound-while-playing-from-the-pico-page) if that firmware is installed: select **QuarkWave USB Audio** as a mono input, enable monitoring, and begin at a low listening level. If it is not installed, you can still check the panel and Uno LED response; the proposed [A0 line output](connection-guide.md#proposed-mono-line-output-from-uno-a0) cannot be used until it is built and tested. On a new Pico, the selected sound is **Warm Pad**. [Startup behavior](technical-guide.md#patch-lifecycle-and-storage).
2. Put your computer or phone on the Pico's configured Wi-Fi network. Open `http://quarkwave.local/`; if that name is unavailable, use the Pico IP address supplied by the builder. **Expected:** the panel appears. [Pico HTTP server](technical-guide.md#browser--pico-interface).
3. Wait for **Pico: Connected** and **Uno: Connected to Pico**. This means the Uno answered the Pico and acknowledged its selected sound. If you see **Uno: Connected to Pico · standalone sound**, an external MIDI input has already been used; its sound is being preserved. [Connection meanings](user-guide.md#get-connected-and-play-a-note).
4. In **Perform**, set **Volume** low, play a browser key, then raise the listening level carefully if you have the USB-audio route ready. The keyboard **Velocity** starts at 100 and affects new notes. **Expected:** the Uno LED display reacts to the note; with the tested USB-audio setup, Logic's mono input can capture it. The physical A0 line output remains untested. [Keyboard procedure](user-guide.md#get-connected-and-play-a-note).
5. Choose **Pluck**, **Solid Bass**, or another sound from the [factory patch list](patch-book.md#factory-presets), then select **Load patch**. Change **Cutoff** or **Morph** in Perform. **Expected:** the controls update and the Uno receives the loaded patch. [Patch behavior](user-guide.md#save-load-and-recover-patches).
6. To keep your change, enter a name, select **Save As**, choose an empty user slot `0–7`, then select **Save to slot**. Confirm before replacing an occupied slot. Factory sounds remain read-only. [Save procedure](user-guide.md#save-load-and-recover-patches).

If a note hangs, use **Panic** in the top strip. If the Pico or Uno connection label shows a problem, use [troubleshooting](user-guide.md#when-something-goes-wrong). The separate RTP-MIDI label reports whether a wireless controller has joined the Pico. To connect a Mac or Windows MIDI app, see [Network MIDI setup](network-midi-setup.md); to play the Uno without the Pico, see [External MIDI controllers](external-midi-guide.md). Record any result in the [hardware test log](hardware-test-log.md).
