# QuarkWave MIDI quick start

**For:** development testers with an assembled instrument. **Status:** source-reviewed, hardware untested (firmware snapshot: 2026-09-22). Use the connection and listening setup supplied with your build; the physical audio circuit and power arrangement are still being documented.

1. Begin with the listening level low. Power the assembled Pico W controller and Uno R4 synth, and connect the build's audio output to your listening setup. **Expected from source:** the Pico starts on **Warm Pad** on a new unit and can sync its selected patch when the Uno responds. The status does not prove that audio is wired correctly. [Startup behavior](technical-guide.md#patch-lifecycle-and-storage).
2. Put your computer or phone on the Pico's configured Wi-Fi network. Open `http://quarkwave.local/`; if that name is unavailable, use the Pico IP address supplied by the builder. **Expected:** the panel appears. [Pico HTTP server](technical-guide.md#browser-pico-interface).
3. Wait for **Pico: Connected** and **Uno: Connected · Pico patch**. If you see **Uno: Connected · standalone sound**, an external MIDI input has already been used; its sound is being preserved. [Connection meanings](user-guide.md#get-connected-and-play-a-note).
4. In **Perform**, set **Master volume** low, play a browser key, then raise the listening level carefully. The keyboard **Velocity** starts at 100 and affects new notes. **Expected:** a note begins when pressed and releases when you let go. Audible behavior still needs a hardware check. [Keyboard procedure](user-guide.md#get-connected-and-play-a-note).
5. Choose **Pluck**, **Solid Bass**, or another sound from the [factory patch list](patch-book.md#factory-presets), then select **Load patch**. Change **Cutoff** or **Morph** in Perform. **Expected:** the controls update and the Uno receives the loaded patch. [Patch behavior](user-guide.md#save-load-and-recover-patches).
6. To keep your change, enter a name, select **Save As**, choose an empty user slot `0–7`, then select **Save to slot**. Confirm before replacing an occupied slot. Factory sounds remain read-only. [Save procedure](user-guide.md#save-load-and-recover-patches).

If a note hangs, use **Panic** in the top strip. If the Pico or Uno connection label shows a problem, use [troubleshooting](user-guide.md#when-something-goes-wrong). The separate RTP-MIDI label reports whether a wireless controller has joined the Pico. To play the Uno without the Pico, see [External MIDI controllers](external-midi-guide.md). Record any result in the [hardware test log](hardware-test-log.md).
